# Derechos, economía y requisitos

Leer manual §§1–3 y §6 para decisiones que afecten dinero, identidad, custodia o transferencias.

1. Identificar actor, actividad, jurisdicción y derecho. Si faltan, trabajar con escenarios condicionales.
2. Separar flujos de plataforma, vehículo, operador y franquiciante. No contabilizar aportes como ventas de plataforma ni como rendimiento.
3. Para cualquier porcentaje registrar numerador, denominador, clase de derechos, fecha y regla. Para distribución registrar base, prelación, reservas, corte, impuestos, disponibilidad y responsable.
4. Comparar alternativa con registro convencional y opción de no implementar cuando sea pertinente. Usar iguales criterios, sin fabricar equivalencias de evidencia.
5. Verificar afirmaciones legales, fiscales, financieras y de estándares en fuentes primarias actuales; guardar URL, fecha consultada, jurisdicción/versión, extracto pertinente y alcance. No convertir un comunicado en norma ni el programa del curso en aprendizaje acreditado.
6. Traducir a requisito comprobable: obligación → sujeto → transición → control → evidencia → prueba. Delimitar qué punto necesita validación profesional local.
7. Si no hay fuente o decisión suficiente, registrar pendiente y efecto preciso. No fijar tasas, derechos, habilitaciones o poderes administrativos solo para que avance el desarrollo.

Salida de una revisión material: conclusión condicionada, alternativas consideradas, Dxx afectados, evidencia y cambios de producto/técnicos derivados. Mantener un ADR propuesto hasta aprobación acreditada.
